# AGENTS.md

## Repository layout

- The workspace root **is** the git repository (remote `github.com/tommasocretu/AR_Camera`, branch `main`); run all git commands from there. Don't create nested repositories.
- The Godot project is `ar-camera_godot/` (project name `ARCamera`).
- `.gitignore` at the repo root is the effective ignore file for the whole tree; `ar-camera_godot/.gitignore` only adds `/android/`.

## Running Godot

Godot is installed only as a Flatpak (`org.godotengine.Godot`, 4.7.2) — there is no `godot` binary on `PATH`. Invoke it through Flatpak:

- Open editor: `flatpak run org.godotengine.Godot --path ar-camera_godot`
- Headless asset reimport after adding files: `flatpak run org.godotengine.Godot --headless --path ar-camera_godot --import`
- Headless editor startup check: `flatpak run org.godotengine.Godot --headless -e --path ar-camera_godot --quit`

`-e` (editor mode) is required for import/validation: plain `--path` tries to run the project and fails with `Can't run project: no main scene defined in the project`, because no main scene is set yet.

## Project constraints

- `project.godot` pins Godot 4.7, the **Mobile** renderer, Jolt physics, and `rendering_device/driver.windows="d3d12"`. This is a mobile AR target: keep it mobile-compatible, don't switch to Forward+ or add desktop-only APIs.
- `.godot/` is generated editor cache (gitignored) — never edit or commit it. `*.import` files are generated by the editor; don't hand-edit them.
- `.gitattributes` normalizes all text files to LF.
